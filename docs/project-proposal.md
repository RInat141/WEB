1. Название и организация

2. Главная сущность и справочник
Главный объект (одна запись процесса): заявка на технику (сломан проектор)
Справочник (вторая таблица, ссылка числом): аудитория
Поле-ссылка (как назовёте в JSON/БД): 'audinceID'
3. Роли и права
| Роль          | Создаёт | Назначает | Меняет статус |
| Преподаватель | да      | нет       | нет           |
| Техник        | нет     | нет       | да            |
| Диспетчер     | нет     | да        | нет           |
Исполнитель не назначает себя, если этого нет отдельным требованием.

4. Сценарий в одно предложение
Кто создаёт → кого назначают → кто меняет статус:

Преподаватель создаёт заявку на сломанный проектор в аудитории → диспетчер назначает техника → техник меняет статус заявки по мере ремонта.

6. Что не входит в семестр
- печать акта выполненных работ;
- датчики и IoT-мониторинг состояния проектора;
- оплата.
7. Запас под ВКР
Привязать проектор по инвентарному номеру и наряд-допуск; считать часы простоя заявки; выгрузить сводку начальнику; забирать простои из журнала обходов; мультикампусность с разными SLA.
8. Чем не копия соседа
Другая организация (КГЭУ, г. Казань), другой главный объект (заявка на технику — проектор), другие роли (преподаватель / техник / диспетчер).
