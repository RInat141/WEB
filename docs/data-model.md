| Термин курса | Термин моей темы |
|---|---|
| Ticket | Заявка на ремонт |
| Site | Транспортное средство / единица техники |
| User | Диспетчер / механик |

## Сущности

### 1. Site (справочник — транспорт)

| Поле | Тип | Ключ | Описание |
|---|---|---|---|
| id | int | PK | Машинный первичный ключ |
| name | string | — | Название / госномер |
| vin | string | — | VIN или инвентарный номер |

### 2. User (пользователь)

| Поле | Тип | Ключ | Описание |
|---|---|---|---|
| id | int | PK | Машинный первичный ключ |
| fullName | string | — | ФИО или логин |
| role | string | — | Dispatcher / Mechanic |

### 3. Ticket (главный объект — заявка на ремонт)

| Поле | Тип | Ключ | Описание |
|---|---|---|---|
| id | int | PK | Машинный первичный ключ |
| number | string | — | Человеческий номер заявки, например `T-2026-0001` |
| title | string | — | Краткое описание неисправности |
| description | string | — | Подробности |
| status | string | — | New / InProgress / Closed / Cancelled |
| siteId | int | FK → Site.id | Транспортное средство |
| createdByUserId | int | FK → User.id | Кто создал заявку |
| assigneeUserId | int, nullable | FK → User.id | Исполнитель (может отсутствовать) |
| createdAt | datetime | — | Дата создания |
| updatedAt | datetime | — | Дата обновления |

## Связи

- Один **Site** — много **Ticket** (1:N).
- Один **User** создаёт много **Ticket** (1:N, `createdByUserId`).
- Один **User** может быть назначен на много **Ticket** (1:N, `assigneeUserId`, необязательная связь).
- У нового Ticket исполнитель может отсутствовать (`assigneeUserId = NULL`).

## Проверка 3НФ

Название участка (транспортного средства) хранится в сущности **Site** один раз.
**Ticket** содержит только внешний ключ `siteId`. При переименовании участка
меняется одна строка в таблице Site, поэтому текст названия не дублируется
в заявках. Аналогично ФИО пользователя не копируется в Ticket — там только
`createdByUserId` и `assigneeUserId`.
