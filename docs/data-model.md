| Термин курса | Термин моей темы |
|---|---|
| Ticket | Заявка на обслуживание оборудования |
| Site | Единица системного оборудования (компьютер / сервер / сетевое) |
| User | Диспетчер / инженер |

Во всех документах используются термины **Ticket**, **Site**, **User**.

Предметная область: учёт системного оборудования (компьютеры, серверы,
сетевое оборудование) и заявок на его обслуживание и ремонт.

## Сущности

### 1. Site (справочник — единица оборудования)

| Поле | Тип | Ключ | Описание |
|---|---|---|---|
| id | int | PK | Машинный первичный ключ |
| name | string | — | Название / инвентарный номер (например, SRV-01) |
| kind | string | — | Тип: Server / PC / Laptop / Network |
| serial | string | — | Серийный номер |

### 2. User (пользователь)

| Поле | Тип | Ключ | Описание |
|---|---|---|---|
| id | int | PK | Машинный первичный ключ |
| fullName | string | — | ФИО или логин |
| role | string | — | Dispatcher / Engineer |

### 3. Ticket (главный объект — заявка на ремонт)

| Поле | Тип | Ключ | Описание |
|---|---|---|---|
| id | int | PK | Машинный первичный ключ |
| number | string | — | Человеческий номер заявки, например `T-2026-0001` |
| title | string | — | Краткое описание неисправности |
| description | string | — | Подробности |
| status | string | — | New / InProgress / Closed / Cancelled |
| siteId | int | FK → Site.id | Единица оборудования |
| createdByUserId | int | FK → User.id | Кто создал заявку |
| assigneeUserId | int, nullable | FK → User.id | Исполнитель (может отсутствовать) |
| createdAt | datetime | — | Дата создания |
| updatedAt | datetime | — | Дата обновления |

## Связи

| Связь (глагол) | Поле в Ticket | Куда ведёт | Тип | Обязательность |
|---|---|---|---|---|
| принадлежит | `siteId` (FK) | `Site.id` (PK) | 1:N | обязательно |
| создаёт | `createdByUserId` (FK) | `User.id` (PK) | 1:N | обязательно |
| назначен | `assigneeUserId` (FK) | `User.id` (PK) | 1:N | может быть NULL |

Пояснения:

- Один **Site** (единица оборудования) — много **Ticket** (заявок на его ремонт).
- Один **User** создаёт много **Ticket**.
- Один **User** может быть назначен на много **Ticket**. У новой заявки исполнитель может отсутствовать.

## Проверка 3НФ

Название, тип и серийный номер единицы оборудования хранятся в сущности
**Site** один раз. **Ticket** содержит только внешний ключ `siteId`. При
переименовании оборудования или смене инвентарного номера меняется одна
строка в таблице Site, поэтому текст названия не дублируется в заявках.
Аналогично ФИО пользователя не копируется в Ticket — там только
`createdByUserId` и `assigneeUserId`.
